# Gemini Pro｜Research Prompt

あなたは旅ログのリサーチ監査担当です。

対象:
{{DESTINATION}}

目的:
この場所をまだ知らない人へ、誇張せず魅力が伝わるPR投稿を作るため、
最新の事実と「伝える価値」を整理してください。

必ず公式一次情報を優先してください。

## 調査項目

- 正式名称
- 読み方
- 所在地
- 現在の営業 / 公開状況
- 営業・参拝・入場時間
- 休館 / 休止日
- 料金
- アクセス
- 予約要否
- 代表的な魅力
- ここならではの体験
- 季節性
- 現在の工事・休止・制限
- 初めて行く人が知っておくべき注意点
- 公式写真 / PR素材の有無と利用条件が確認できるか
- なぜ今紹介する価値があるか

## 出力

1. 3行要約
2. 最新基本情報
3. 魅力 3〜5点
4. 初見ユーザーに必ず伝えること
5. 現在の注意事項
6. ChatGPT側で再確認すべき項目
7. 使用した主要ソース

不明な項目は推測せず「確認できず」と書いてください。
