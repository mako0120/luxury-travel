# 旅ログ｜PHOTO INTEGRITY POLICY

更新: 2026-10-22

## 絶対原則
実際の場所の写真は、**綺麗にするだけ**。
写っている事実そのものは絶対に変更しない。

## 許可
- 露出 / 明るさ
- ハイライト / シャドウ
- ホワイトバランス
- 自然なコントラスト / 彩度
- 軽いノイズ低減 / シャープネス
- 軽微なレンズ歪み / 水平補正
- 必要最小限の4:5クロップ
- 非生成の通常リサイズ

## 絶対禁止
- 人・物・建物・料理・温泉・植物・看板・車等の追加 / 削除 / 移動 / 置換
- 人消し / 物消し
- 空置換
- 季節 / 天候 / 昼夜変更
- AI背景拡張
- Generative Fill / Magic Edit
- 湯気・光・反射等の生成追加
- AIで存在しない細部を作る超解像
- 過度なHDR / 彩度変更
- 実写の代わりにAI生成画像を使用

## Canva
FULL PHOTO MASTERの仮画像はレイアウト確認用。
本番は必ず実際の場所の実写へ100%置換する。

## QA
- [ ] 元画像と写っている内容が同じ
- [ ] 追加物ゼロ
- [ ] 削除物ゼロ
- [ ] 空・天候・季節が同じ
- [ ] 建物・設備・料理・温泉の形が同じ
- [ ] AI生成編集ゼロ
- [ ] 補正は自然
- [ ] クロップで場所の印象を変えていない

**「綺麗にする」は可。「作り変える」は禁止。**
