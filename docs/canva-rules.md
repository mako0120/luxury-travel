# Canva制作ルール｜旅ログ

## 1. 基本

既存の「みんなの旅ログ｜MASTER TEMPLATE」を使用する。

- Instagram縦型 4:5
- 1080×1350px
- 5ページ
- 既存のフォント・文字並び・余白感・写真枠をできる限り維持する

テンプレートを「派手に作り替える」のではなく、
写真と内容を入れ替えて場所の魅力を伝える。

## 2. デザイン思想

**写真が主役。デザインは案内役。**

- グラデーションや装飾を過剰に追加しない
- 写真の色を不自然に変えない
- 大量のアイコンやステッカーを載せない
- 文字は写真を説明する最低限にする
- 高級感は余白・文字組み・写真選びで出す
- 「広告バナー」より「上質な旅行雑誌」に近づける

## 3. P1 表紙

最もその場所らしい写真1枚を使う。

### 文字数
- 上段: 10文字以内
- 2行目: 10文字以内
- 施設 / スポット名: 7文字以内
- 縦書き: 14文字以内

正式名称が7文字を超える場合のみ、
誤認を生まない自然な略称を使う。

### 配置
- 文字と文字を重ねない
- 顔、料理、鳥居、建物、山、海など主役を隠さない
- 空、壁、水面など自然な余白を使う
- 表紙だけで「どんな場所か」が伝わる写真を選ぶ

## 4. P2〜P5

原則として既存の上下写真枠を維持する。
写真を大きく見せ、文章は短く。

1ページにつき:
- 見出し 1つ
- 本文 1〜3文
- 必要な場合のみ小さな補足

文字を増やすより、次ページへ役割分担する。

## 5. 写真の構成

5ページ全体で「同じ場所の同じ角度」ばかりにしない。

理想例:
- P1: 象徴的な全景
- P2: 全景 + 入口 / 外観
- P3: 独自体験 + 景色
- P4: 名物 / ディテール + 別の魅力
- P5: アクセスをイメージできる外観 / 周辺 + 代表写真

## 6. 写真加工

許可:
- トリミング
- 回転補正
- 軽微な明るさ・コントラスト補正
- 枠に合わせるための余白調整

禁止:
- AIで背景を足す
- AIで存在しない人・料理・建物・景色を生成
- 実景を別季節・別天候へ変える
- 被写体を本来と異なる状態へ変更

## 7. コピーの方向

この投稿は「場所を知らない人への紹介PR」。

表紙は興味を引く。
中面は「知るほど行きたくなる」構成にする。

良い例:
- 海へ続く鳥居
- 静かな森に泊まる
- 朝だけ出会える景色
- 島時間を味わう宿

避ける:
- 絶対行くべき
- 神すぎる
- ヤバすぎる
- 日本一（根拠がない場合）
- ここ知らないと損

## 8. QA

- 写真が一番目立っているか
- 装飾が写真を邪魔していないか
- 文字サイズに無理がないか
- スマホで読めるか
- 見出しだけで内容が把握できるか
- 5ページで場所の全体像が分かるか


## 9. Canva Autofillを第一候補にする

MASTER `DAHVoXJDBFw` はCanvaの名前付きAutofillフィールドを持つことを確認済み。

### 実測したMASTER
- Design ID: `DAHVoXJDBFw`
- 5ページ
- 1080×1350
- P1: メイン写真1枚
- P2〜P5: 上下2枚の写真枠
- Autofill対応: **yes**

### 主要テキストフィールド

表紙:
- `cover_line1_max10`
- `cover_line2_max10`
- `cover_line3_max7`
- `cover_vertical_max14`
- `cover_kicker`
- `cover_title`
- `cover_side_note`
- `area`
- `facility_name`

P2:

- `room_body`
- `room_image_1`
- `room_image_2`

P3:
- `feature1_title`
- `feature1_body`
- `feature1_image_1`
- `feature1_image_2`

P4:
- `feature2_title`
- `feature2_body`
- `feature2_image_1`
- `feature2_image_2`

P5:
- `price_title`
- `price_body`
- `price_image_1`
- `price_image_2`

テンプレートには `point1_*` / `point2_*` / `point3_*` 系フィールドも存在する。
使用する場合は、その時点のMASTERを `get_design_dataset` で再確認してから使う。

### 推奨制作方法

1. MASTERのdatasetを取得し、フィールド構造が変わっていないか確認。
2. ユーザー写真または権利確認済み素材をCanva Assetsへ登録。
3. Production BriefからAutofillデータを生成。
4. `autofill_design` で**新しいデザインとして生成**する。MASTERを上書きしない。
5. 5ページのサムネイル / プレビューを確認。
6. 必要な微調整のみediting transactionで行う。
7. QA後、専用フォルダへ移動しNotionを更新。

### Autofillを使わない場合

次の場合だけ直接editing transactionへ切り替える。

- MASTERのdatasetが変わっている
- ページ固有の複雑なレイアウト変更が必要
- Autofillで写真のクロップが著しく不適切
- テキストフィールドが案件に合わない

Autofill後もQAは省略しない。
