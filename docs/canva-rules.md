# Canva制作ルール｜旅ログ

## 現行の正式スタイル

現在の第一制作スタイルは **FULL PHOTO STYLE V3**。

必ず先に読む:
- `docs/canva-full-photo-style-v3.md`

### 要約
- 1080×1350px
- 標準8ページ、案件により6〜8ページ
- 原則1ページ1枚の全面写真
- 白い短文1つだけ
- 写真品質を最優先
- 詳細情報はキャプション側
- 装飾は最小限
- 実在場所の実写を使用
- 画質が弱い写真で枚数を埋めない

## 旧MASTER

旧MASTER:
`DAHVoXJDBFw`

旧MASTERは5ページ・P2〜P5上下2枚型であり、
V3の参考投稿とは構造が異なる。

以下の場合のみ互換用として使う:
- ユーザーが旧5ページ型を明示指定
- 既存投稿の修正
- V3向けCanvaテンプレートが一時的に利用できない

新規制作ではFULL PHOTO STYLE V3を優先する。

## 写真

最優先ルール: `docs/photo-integrity-policy.md`

写真の品質が投稿品質そのもの。**ただし、綺麗にするために実際の場所を作り変えてはいけない。**

- ユーザー提供の元画像を最優先
- 公式/PR素材は利用条件確認
- 可能な限り高解像度
- スクリーンショットを最終素材にしない
- AI生成・背景拡張・Generative Fill・物体削除・空置換・季節/天候変更・実景改変は全面禁止
- 写っている物の追加 / 削除 / 置換はしない
- 露出、WB、ハイライト、シャドウ、コントラスト、自然な彩度、ノイズ低減、軽いシャープネス、水平、通常クロップのみ可
- アップスケールは非生成の通常リサイズのみ

## QA

FULL PHOTO STYLE V3のQAチェックリストを使う。
写真が弱い場合は、文章が完成していても完成扱いにしない。
