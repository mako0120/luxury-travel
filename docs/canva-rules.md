# Canva制作ルール｜旅ログ

## 現行の正式スタイル

現在の第一制作スタイルは **FULL PHOTO STYLE V3**。

必ず先に読む:
- `docs/canva-full-photo-style-v3.md`

### 要約
- 1080×1350px
- 標準8ページ、案件により6〜8ページ
- 原則1ページ1枚の全面写真
- 白い短文1つだけ
- 写真品質を最優先
- 詳細情報はキャプション側
- 装飾は最小限
- 実在場所の実写を使用
- 画質が弱い写真で枚数を埋めない

## 旧MASTER

旧MASTER:
`DAHVoXJDBFw`

旧MASTERは5ページ・P2〜P5上下2枚型であり、
V3の参考投稿とは構造が異なる。

以下の場合のみ互換用として使う:
- ユーザーが旧5ページ型を明示指定
- 既存投稿の修正
- V3向けCanvaテンプレートが一時的に利用できない

新規制作ではFULL PHOTO STYLE V3を優先する。

## 写真

写真の品質が投稿品質そのもの。

- ユーザー提供の元画像を最優先
- 公式/PR素材は利用条件確認
- 可能な限り高解像度
- スクリーンショットを最終素材にしない
- **実際の場所の内容は絶対に変えない**
- 人・物・建物・空・海・料理・植物等の追加/削除/移動/置換は禁止
- AI生成、Generative Fill、背景拡張、空置換、人消し、物消しは禁止
- 許可するのは露出、WB、ハイライト、シャドウ、コントラスト、自然な彩度、軽いシャープ/ノイズ低減、水平垂直などの非生成補正のみ
- クロップは必要最小限。主役や重要景観を切るなら別写真を使う
- 補正後も「同じ場所・同じ瞬間」であることを最優先する

## QA

FULL PHOTO STYLE V3のQAチェックリストを使う。
写真が弱い場合は、文章が完成していても完成扱いにしない。
