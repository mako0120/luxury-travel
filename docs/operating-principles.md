# 運用原則（Operating Principles）V2

## 1. 最終目的

「旅行先を探すならこのアカウントを見ればいい」と思われる旅行メディアをつくる。

単なる映え紹介ではなく、まだ十分知られていない宿・観光地・体験を含め、
その場所の良さを初見の人にも分かる形で幅広く紹介する。

優先KPI:
保存率 / シェア率 / 完読率 / プロフィール遷移 / フォロー転換 / 旅行検討・予約行動。

## 2. PRの思想

投稿は「旅先紹介PR」として制作する。

- 写真を主役にする。
- 派手な装飾で場所そのものを負けさせない。
- 「どんな場所か」を最優先で伝える。
- 景色だけでなく、特徴、体験、文化、食、アクセス、注意点まで必要に応じて紹介する。
- 誇張・煽り・実体験捏造をしない。
- 有名スポットだけでなく、知られていない場所を積極的に発見する。

## 3. 二段階運用

### Discovery
候補発見・初期調査・評価・キャプション草案を行う。

### Production
Notionに登録された制作対象について最新情報を再確認し、
実写写真を使ってCanva投稿を完成させる。

**Notion登録 = 制作承認済み。Productionではスコアで除外しない。**

## 4. 情報源

優先順位:

1. 施設・観光地の公式サイト
2. 自治体 / 観光協会
3. 公式予約ページ
4. 公式SNS / 公式Press Room
5. 運営会社・ブランド公式情報
6. 信頼できる予約サイト・レビュー・報道

変動情報は必ず制作直前に再確認する。

## 5. Discovery採点

候補探索では100点満点で編集評価してよい。

| 項目 | 配点 |
|---|---:|
| 口コミ評価 | 25 |
| 口コミ件数・信頼性 | 15 |
| 独自体験 | 20 |
| 写真・動画で伝わる魅力 | 15 |
| 価格に対する体験価値 | 10 |
| SNS話題性 | 10 |
| アクセス・情報鮮度 | 5 |

基準値は探索効率のために使う。
**Productionの制作可否には使わない。**

## 6. Hidden Gem

口コミ数や知名度が低くても、次を満たす場所は積極的に扱う。

- 公式情報が確認できる
- 現在営業・公開している
- 独自性がある
- 写真・体験・背景のどれかに「人へ伝える価値」がある

「知られていないから弱い」ではなく、
「知られていない良さをどう伝えるか」を考える。

## 7. ファクトチェック

最低でも一次情報を1つ以上確認する。
料金・営業時間・参拝時間・休止日・アクセス・予約条件など変動情報は最新情報を優先する。

正確に確認できない数字は推測しない。

## 8. 写真

優先順位:

1. ユーザー本人が提供した写真
2. 明確に利用可能な公式PR素材
3. 自治体・観光協会等で利用条件が確認できる素材
4. その他、利用許諾が確認できる実写素材

禁止:

- 実在施設・観光地をAI生成画像で置き換える
- AI補完で実際には存在しない景色や設備を作る
- 出典不明素材
- ウォーターマーク付き素材
- 権利条件不明の画像を「公式だから使える」と決めつける

許容:
露出、明るさ、WB、ハイライト/シャドウ、自然なコントラスト、軽いシャープ/ノイズ低減など、写真の内容を一切変えない非生成補正のみ。

クロップは必要最小限とし、主役・景観・建築など重要要素を切って印象が変わる場合は不許可。

絶対禁止:
人消し、物消し、物体追加、被写体移動、空置換、背景拡張、Generative Fill、季節/天候/時間帯変更、建物・料理・温泉・海・山・植物等の改変、存在しない細部を生成するAI補完。

## 9. Canvaデザイン

詳細は `docs/canva-rules.md` を参照。

原則:
- 1080×1350px（4:5）
- 5ページ
- 写真主役
- 装飾は最小限
- 旅ログの既存トーン・フォント・余白を維持
- 表紙は一目で場所の特徴が分かる実写を選ぶ

## 10. 文章

- 短く、分かりやすく。
- 旅行したくなるが、広告コピーだけにならない。
- 初見の人が「ここは何？」と迷わない。
- 実体験ではない場合、実体験風に断定しない。
- 価格・営業時間などは条件と鮮度を明示する。

## 11. Gemini Pro

Gemini ProはAPIなしで第二AIとして使用する。

役割:
- Deep Researchによる独立再調査
- 写真の比較・分類・表紙候補選定
- 初見ユーザーに伝わるかのレビュー
- 完成Canva PDFの視覚QA

Geminiの意見は参考情報であり、公式情報と本リポジトリのルールが優先。

詳細: `docs/gemini-pro-workflow.md`

## 12. 最終品質

公開前に最低限確認する。

- 事実が最新か
- 写真が実在の場所を正しく表しているか
- 写真と本文が一致しているか
- 初見で場所の特徴が分かるか
- 文字切れ・重なりがないか
- 写真を装飾で隠していないか
- AI生成素材が紛れ込んでいないか
- 権利条件に問題がないか
