## 最重要
- 新規投稿は必ず `DAHYun12-UY` をコピーして作る
- MASTER本体は上書きしない
- 7ページ固定
- 写真7枚固定
- 1ページ1写真
- 上下2枚分割は禁止
- 中央分割線は禁止
- コラージュは原則禁止
- 元デザインの文字配置・フォント・余白感・見出し構造を継承
- 写真を最も綺麗に見せることを最優先

## 写真
優先順位:
1. ユーザー提供元画像
2. 利用条件確認済み公式PR素材
3. 自治体・観光協会等の利用可能な実写

品質:
- 長辺2000px以上を優先
- 可能なら2160×2700相当以上
- スクリーンショット、SNS再圧縮、ピンぼけ、強いノイズ、白飛び/黒潰れ、ウォーターマーク入りを避ける
- 7枚を埋めるために弱い写真を使わない

許可する補正:
- 露出
- ハイライト
- シャドウ
- コントラスト
- WB / 色温度
- 自然な彩度
- 軽いシャープ / ノイズ低減
- 水平垂直
- 必要最小限の4:5クロップ

禁止:
- AI生成実景
- Generative Fill
- 背景拡張
- 空置換
- 人消し / 物消し
- 建物、料理、温泉、植物、天候、季節等の追加・削除・置換

## 7ページ構成
1. P1 COVER / HOOK — 最強写真、場所名、エリア、表紙コピー
2. P2 WHAT — どんな場所か
3. P3 SIGNATURE — 代表的な魅力
4. P4 STORY — 歴史・由来・文化・建築等
5. P5 ANOTHER VALUE — 別の魅力
6. P6 EXPERIENCE / DETAIL — 体験、食、朝夜景、周辺等
7. P7 CLOSE — 最後の余韻、重要な訪問前情報、保存につながる締め

宿以外の観光地に客室・温泉等を機械的に当てはめない。

## テキスト
- 表紙は元デザインの構造を維持
- P2〜P7は上部見出し＋下部短文を基本
- 長文・詳細情報はキャプションへ
- 文字切れ、重なり、主役への被りを禁止
- 煽りすぎる表現を避ける
- 未訪問を実体験として書かない

## 制作フロー
1. Notionから対象取得
2. Webで最新公式情報を再確認
3. `DAHYun12-UY` をcopy_design
4. 高品質実写を7枚確保
5. 写真を非生成補正
6. P1〜P7へ1枚ずつ差し替え
7. コピー差し替え
8. スマホ前提で7ページQA
9. 中央線・上下分割がないことを確認
10. 完成後 `ラグジュアリー旅行` へ保存
11. Notion更新
12. キャプション工程へ渡す
